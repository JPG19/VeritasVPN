Frequently asked questions

Everything you need to know about VeritasVPN.

Unlike most VPNs, we open-source everything — clients, server provisioning scripts, infrastructure code. Our servers run entirely in RAM with no disks. We use WireGuard exclusively (the most auditable protocol). You can verify our no-logs claims by reading the server code yourself. We also support fully anonymous accounts (no email required) and Monero payments.

We never store: IP addresses, connection timestamps, bandwidth usage per user, DNS queries, browsing history, or any traffic data. We only store the minimum needed to operate: your hashed account ID, subscription tier, and aggregate server load metrics. Everything else is ephemeral. When a server reboots, all runtime state is wiped from RAM — there's nothing on disk to recover.

WireGuard has been extensively audited, runs in the Linux kernel, and consists of only ~4,000 lines of code — making it far easier to audit and secure than OpenVPN (70,000+ lines) or IPsec (400,000+). It's also significantly faster. We believe a smaller attack surface is better for privacy. Every modern device supports WireGuard natively or via our apps.

Yes. When you create an account, you receive a randomly generated account ID — no email, name, or phone number required. This is your only credential. Save it securely, as it's the only way to recover your account. Combined with Monero payments, you can be completely anonymous from sign-up to browsing.

A warrant canary is a regularly-updated, cryptographically-signed statement that we have NOT received any secret government requests (national security letters, gag orders, etc.). If the canary stops being updated, it signals that we may have been legally compelled to remain silent about a government request. It's a legally-tested method that privacy services use to warn users without violating gag orders.

Windows, macOS, Linux, iOS, and Android. All client apps are fully open-source. We also provide a CLI client for headless servers and routers. Configuration files are standard WireGuard format, so you can use the native WireGuard client on any platform if you prefer.

We have servers in 20+ locations across North America, Europe, Asia, South America, and Oceania. All servers are in privacy-friendly jurisdictions. We use multiple independent hosting providers (Hetzner, Vultr, BuyVM) to avoid single-provider dependency. Our full server list and real-time status is available to all users — no account needed to check.

When enabled, the kill switch blocks all internet traffic that doesn't go through the VPN tunnel. If the WireGuard connection drops for any reason, your real IP is never exposed. We implement this differently per platform: nftables on Linux, pfctl on macOS, and Windows Filtering Platform (WFP) on Windows — all at the OS firewall level, not just the application level.
